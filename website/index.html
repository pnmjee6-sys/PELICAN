Pelican is in early preview for Chrome and Brave. Set up your personal memory in a few quick steps.

Set up my memory ↗Download extension ZIP ↗

Unzip it, open brave://extensions or chrome://extensions, turn on Developer mode, then choose Load unpacked and select the unzipped folder. Pin Pelican and sign in with the same account as this website.
